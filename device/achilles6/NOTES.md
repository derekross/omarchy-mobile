# Lenovo Tab M10 FHD Plus (TB-X606F / `achilles6`) — Bring-up Notes

Hardware: MediaTek Helio P22T (`MT6765`) + `MT6357` PMIC, 1200x1920 DSI panel (`HX83102P` + `SGM37604A` backlight), Himax `HX83112B` touchscreen, `BQ25601` charger + `MT6357` fuel gauge, MTK `gen4m` Wi-Fi / `btmtk` Bluetooth, dual external speaker amplifiers (`GPIO 151` & `GPIO 153`) fed from `MT6357` stereo headphone buffer (`int_hp_buf`).

Kernel tree (external fork): [`TMartinPPC/android-kernel-mt6765-rabbitr1` (`achilles6` branch)](https://github.com/TMartinPPC/android-kernel-mt6765-rabbitr1/tree/achilles6), based on `haretic/android-kernel-mt6765-rabbitr1` (`7.3.5-android17-0-r1`, carrying MT6765 CONSYS/PowerVR/display drivers).

Non-A/B `CONTRIBUTING.md` §3.1 tracking issue: [#1071](https://github.com/derekross/omarchy-mobile/issues/1071).

## Pre-Flash Backup and Write History (`CONTRIBUTING.md` §3.1)

- **Full read-only backup (2026-11-17, before first flash):** Captured off-device via `mtkclient` before writing any partition — `gpt.bin`, `gpt_backup.bin`, `preloader_achilles6_row_wifi.bin`, `hwparam.json`, and all 40 eMMC partitions including stock `boot.bin`, `dtbo.bin`, `lk.bin`, `para.bin`, and calibration/identity partitions (`nvram.bin`, `nvdata.bin`, `protect1.bin`, `protect2.bin`, `proinfo.bin`). Stored locally outside the repository and off GitHub.
- **How `boot` was written (2026-11-17 to 2026-11-21):** Stock TB-X606F LK ignores `fastboot boot` (falls back to the flashed `boot` partition), so bring-up kernel images were flashed manually to `boot` only via `fastboot flash boot <image>.img && fastboot reboot` (culminating in kernel `#21` with the `panel-himax-hx83102.c` porch fix on 2026-11-21). Stock `dtbo` and all other boot/calibration partitions were never written.
- **How `userdata` was written (2026-11-21):** During Stage 4 bring-up (prior to adding eMMC support to the shared `initramfs/init` storage guard), `userdata` (`/dev/mmcblk0p38`, 109 GiB) was formatted once with `mkfs.ext4 -L omamobile-root /dev/mmcblk0p38` and populated via `rsync` from the local NFS rootfs while booted from a guarded initramfs that removed `/dev/mmcblk0` and forced all other 39 partitions read-only (`ro = 1`).
- **What the tablet runs now:** Standalone Arch Linux ARM / Omarchy `4.5.0-3` on `userdata` (`/dev/mmcblk0p38`, ext4, 96 GiB free) with kernel `7.3.5-android17-0-r1-itskenny0+ #21`. `device/achilles6/device.conf` remains `BOOT_METHOD=ram-only` until the non-A/B §3.1 entry (#1071) and the shared eMMC storage guard PR land; all future writes to `boot` or `userdata` will go through the project's tools.

## Stage 4 Hardware Verification (2026-11-20 / 2026-11-21)

- **Display (`mediatek-drm`, `panel-himax-hx83102.c`):** Native DSI-1 (`1200x1920@63.54Hz`) with `SGM37604A` backlight. Panel init sequence and horizontal timings come from Lenovo's GPL kernel source for TB-X606F; fixed `panel-himax-hx83102.c` horizontal porches from pre-multiplied byte counts (`84/32/68`) to stock pixel counts (`32/14/26`, `htotal = 1272`), eliminating the ~20 px bottom-edge repeated strip. `STRICT_DEVMEM=y` is kept enabled; all display bring-up stays in `mediatek-drm`.
- **GPU (`pvrsrvkm`):** PowerVR Rogue GE8320 kernel driver (`pvrsrvkm`) probes and exposes a render node (`boots` in the device matrix); userspace currently forces software rendering (`WLR_RENDERER_ALLOW_SOFTWARE=1`) until a PowerVR userspace driver is available.
- **Touchscreen (`himax_hx83112b.c`):** Fixed 68-byte event packet read (56-byte touch + 12-byte stylus block) and all-zero checksum filter; multitouch verified in Hyprland, lock screen, and shell.
- **Buttons:** Power (`mtk-pmic-keys`) and Volume Up/Down (`mt6779-keypad`, `KP_MEM1` bits 0/1) verified in Linux.
- **Battery & Charging (`bq256xx_charger.c`, `mt6357-gauge.c`, `mt6765-lenovo-tb-x606f.dts`):** Added 21-point 4.4 V Li-ion OCV table (`power_supply_batinfo_ocv2cap()`) and removed dummy `bq256xx-battery` registration; `upower` and shell report accurate percentage and charging state. Charger/battery DT limits: `BQ25601` `input-current-limit-microamp = 2.0 A`, `input-voltage-limit-microvolt = 4.5 V`; `bat_pack` `constant-charge-voltage-max-microvolt = 4.4 V`, `constant-charge-current-max-microamp = 2.04 A`, design capacity `5100 mAh`.
- **Wi-Fi & Bluetooth (`gen4m`, `btmtk`):** Fixed `rtnl_lock` boot deadlock in `gl_cfg80211.c`, disabled probe-time `ap0`/`p2p0` creation (`CFG_DRIVER_INITIAL_RUNNING_MODE=0`, `RegP2pIfAtProbe=0`). Firmware (`WIFI_RAM_CODE_6765`, `ROM_PATCH_6765`, PowerVR firmware) is extracted from the owner's own stock `vendor` partition and is never committed. Wi-Fi connects to WPA2/WPA3 APs with internet access; Bluetooth scans and discovers nearby devices.
- **Stereo Speakers (`mt6765-mt6357.c`, UCM2):** Protected the 3-pulse GPIO 151/153 amplifier enable sequence with `local_irq_save()`/`local_irq_restore()`. Routed `Speaker` UCM profile through MT6357's stereo headphone buffer (`Headphone Left/Right Source = DAC`, `Headphone Switch = 1`, `Speaker Switch = 1`, matching stock `AudioParamOptions.xml` `MTK_AUDIO_SPEAKER_PATH="int_hp_buf"`). Audible playback verified via PipeWire/WirePlumber.
- **USB Gadget (`device/achilles6/kernel.config`):** Enabled `CONFIG_MUSB_PIO_ONLY=y` (disabling `CONFIG_USB_INVENTRA_DMA`, which stalls under heavy bidirectional USB gadget traffic on MT6765).
- **System Updates (`omarchy update`):** Verified `omamobile-update check` (`Omarchy 4.5.0-3; 0 package(s) to update`, `Phone patches: ok`).

## Known Issues / TODO

- **SDDM / lockscreen occasionally half-black on boot:** Sometimes on boot, one half of the SDDM/lockscreen renders black. Turning the screen off and back on (short Power press twice) clears it immediately.
- **Hardware Fastboot key combo (`Power + Vol-`) on stock `S301068` firmware:** Disassembly of stock `lk.bin` (`boot_mode_select` at `0x3980..0x3a6c`) shows LK checks `Power` + `KP_MEM1` bit 1 (`Vol-`) for Fastboot (`fastboot-hotkey=1` in `para`) and `Power` + `KP_MEM1` bit 0 (`Vol+`) for META mode (`0x1e2e8`). Live LK RAM logs (`mblock-3-log_store` at `0x7ffc0000`) show that while `Power + Vol+` enters META mode reliably, `KP_MEM1` bit 1 (`KPCOL1` / `GPIO94`) never registers as pressed inside stock Preloader/LK (even though the same bit works in Linux once `mt6779-keypad` applies `kpd_pins_default`). Use `reboot bootloader` (or `reboot-to bootloader`) from Linux to enter Fastboot, hold `Power` alone for ~10 s for a hardware reset (`reboot_longkey`, e.g. to exit META mode), and use `mtkclient` via Preloader/BROM (`0e8d:2000`) for emergency unbrick (restoring only the backed-up stock `boot.bin` to `boot`).
- **Black bootloader screen during LK:** LK's display probe falls back from `mipi_hx83102p_inx_video_1200p` to `mipi_ft8201_video_1200p`, leaving the Lenovo logo / Orange State screen dark until Linux takes over the panel.
- **Shared eMMC storage guard & device package:** Follow-up PRs will add eMMC (`mmcblk0`, `mmcblk0boot*`, `mmcblk0rpmb`) support to the shared `initramfs/init` storage guard and submit `packages/omamobile-device-achilles6/`.
- **Suspend (`s2idle`):** Verified end-to-end auto-sleep via `omamobile-sleepd` (`s2idle` / `freeze`, Power button wake on IRQ 160 `mt6358-irq`, Wi-Fi auto-reconnect with a `systemd-sleep` `/dev/wmtWifi` hook). `deep` (`mem`) SPM sleep and `psci_idle` `cpu-off` broadcast timer are still under investigation.
- **Not yet brought up:** Accelerometer / autorotate, cameras, GNSS/GPS, microphone / headset jack verification, `deep` SPM suspend, PowerVR userspace acceleration.
