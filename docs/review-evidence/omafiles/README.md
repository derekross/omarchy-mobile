# Files interface previews

These images and the animated recording show the actual Files QML with the
real backend operating on a temporary home containing fictional documents.
They are offscreen previews, not phone captures or device performance evidence.
The light and dark examples use Omarchy Commons theme tokens; portrait and
short-viewport interaction checks are described in the package README.

The animation is encoded from the timestamped native component recording.
The source capture has 228 frames over 7.640 seconds (about 29.71 captured
frames/second); encoding is not a claim about phone refresh rate or animation
performance. No interpolated frames are added. Existing project MIT notices
and the rendered fallback font's OFL notice remain in the package.
