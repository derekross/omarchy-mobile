# Native Search: Ask Agent previews

Actual rendered production QML components using genuine Omarchy Commons/UI
modules, neutral theme scenery and fictional app/conversation fixtures.
No private phone capture, account, prompt history, wallpaper or widget is used.
The selected Codex name in this fixture demonstrates one configured agent;
the UI label follows the actual default agent in normal use.

The Ask card opens a conversation with an editable draft. The recording then
clicks the actual Send control, supplies neutral reply events to the actual
controller and returns to Search using Back. This preview transport is inert;
no model, network, credentials or agent CLI is invoked by the visual harness.
The separate integration fixture connects the real QML/Python transport to an
inert CLI to exercise the functional protocol.

Portrait previews use a 420 x 580 available viewport; landscape is 740 x 320.
No keyboard is drawn or simulated. The tint is rendered over neutral scenery;
o compositor blur or physical phone interaction is qualified here.

The lossless animated WebP is encoded from106actual captures spanning3977ms,
with the original intervals and a median interval for the final frame
(total4014ms). The encoder merges identical frames into28encoded frames.
No interpolated frames, physical FPS or measured compositor smoothness is
claimed. Existing source attribution and licenses remain intact.

The compact 320 x 320 preview includes the responsive control-width correction.
Buttons can shrink and elide long labels instead of expanding the composer
beyond its viewport. The full accessible button name remains available.
